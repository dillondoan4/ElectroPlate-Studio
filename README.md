# ElectroPlate-Studio
This website is designed to produce g-code for in situ copper electroplating. In order for the Bambu A1 to combine the normal printing and electroplating into one continuous process, this website merges together, at minimum, two CAD files: the base part to be copper plated, and the path of the copper plating itself. It allows for the user to adjust the plating parameters before merging the files, and also allows for the user to preview the print with the g-code simulator. The simulator is especially helpful for spotting out issues before beginning longer prints. All coding credits go to Maxwell Calvert, who developed this g-code merger while I was doing research with him at Widener University in the Mechanical Engineering research lab. My contributions to the g-code merger were to provide feedback on how the system could improve and be easier to use for the electroplating process.
